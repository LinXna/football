# 脚本层

这里收纳数据采集、推荐、复核和本地自动化入口。

迁移约定：

- Python 脚本必须通过项目根目录解析 `sources/`、`output/` 和别名库。
- PowerShell 脚本必须通过自身位置取得项目根目录，不能假设当前工作目录。
- 根目录旧入口在迁移完成前保留为兼容启动器。
- 任何脚本迁移后都必须通过离线测试和至少一次 `--help` 检查。

计划目录：

```text
scripts/
  python/      # 采集、推荐、复核、别名管理
  powershell/  # Windows 流程编排
  cmd/         # Windows 兼容启动器
```

当前根目录脚本仍是正式入口，待路径参数化完成后再移动，避免破坏现有自动化任务。
