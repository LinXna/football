### 第二阶段加固

- 比分写入统一校验为非负整数；拒绝缺失比分、负数、小数以及大于完场比分的半场比分。
- 复盘结果限制为受支持状态，并将单场复盘同步到滚球/赛前决策文件。
- 批量导入限制 5000 场，拒绝缺少主队或客队的数据，取消只匹配一支球队的模糊覆盖。
- 数据补充不再把 `PASS/C` 自动升级成 `WATCH/B`；新导入记录固定从 `RESEARCH/C` 开始。
- 修正带时区开赛时间到北京时间的转换，并正确累计“小时＋分钟”倒计时。
- 正式命中率、ROI、评级、玩法和串关统计严格排除机器候选；唯一方向不再因赔率变化重复计数。
- 未提供模型评分时保存为 0，不再虚构 72/75 分；启发式评分不再自动写入预测概率字段。

### 第三阶段：并发、API 与概率校准

- Node JSON 存储增加跨进程排他锁、10 秒超时、进程存活判断及崩溃残留锁恢复。
- 台账、别名、批量导入、比分补录和清理接口在完整“读—改—写”周期内持锁，多文件仍原子提交。
- Python 推荐、正式记录和复盘脚本接入同一个 `.json-store.lock` 协议，避免与网页 API 互相覆盖。
- 并发压力测试由 4 个 Node 进程和 1 个 Python 进程共同完成 100 次增量更新，结果无丢失。
- 新增隔离临时项目目录的真实 HTTP 集成测试，覆盖正式推荐校验、去重、补分、复盘、清理和受保护数据。
- 新增 `/api/calibration`：只读取正式、单场、已结算且具有明确概率的样本，输出 Brier Score、ECE、
  概率分箱、ROI、最近 30/90 条滚动指标，并对少于 30 条样本明确禁止下结论。
- 台账页面新增概率校准摘要；正式推荐保存明确的 `prediction_probability`，不使用规则分数代替。

本阶段验证：TypeScript/API/并发/校准测试 10 项通过；Python 28 项通过；类型检查、生产构建、
开发服务健康检查及差异格式检查通过。

### 第四阶段：全写点原子化与分层校准

- Node 读取JSON时只对“不存在”使用默认值；已存在但为空或解析失败的文件不再伪装成空数据。
- 每次成功覆盖保留上一版 `.bak`。损坏文件先复制为 `.corrupt-时间戳.json`；有效备份存在时
  自动恢复，否则抛出明确错误并阻止写入。
- `requireJsonWrites` 写入前同时验证新数据和现有文件，避免未经过读取的直接写操作覆盖损坏数据。
- Python新增 `read_json_strict` 与 `atomic_write_json`，采用同一跨语言锁，执行临时文件写入、
  `flush/fsync`、重新解析、持久备份和 `os.replace` 原子替换。
- `football_live.py` 的候选、趋势历史、自动别名，别名管理工具，推荐、记录、复盘及整合导出
  已全部移除直接 `write_text` JSON写入。
- 人工输赢继续保留，同时记录 `outcome_source=manual_user_confirmed`、记录时间和历史结果，满足审计。
- 校准新增按滚球/赛前、玩法、联赛、评级和模型版本分层；少于15条标记“样本不足”，15至29条

## 2026-08-20 预测引擎量化重构与串关去重加固复审

本轮针对“数据解析完备但基础预测准确率低”、“角球静态文本误导”与“串关重复堆砌核心腿”开展全链路系统性诊断与修正。

已完成修复与优化：

1. **角球压制与动态计算彻底贯通**：
   - 移除 `recommend_live.py` 中静态残留的“包含角球4-0级压制”字样，改为实时动态统计输出 `(角球主X-客Y，纪律主A-客B)`；
   - 提取角球净差、每 10 分钟爆发速率与边路挤压比率，将角球贡献 $xG_{corner}$ 直接注入滚球剩余进球期望 $\lambda_{rest}$ 与优势指数 Dominance。
2. **非线性时段衰减与体能换人发力期**：
   - 替换粗糙的 `(90 - min) / 90` 线性均摊，引入分段加权函数：56'-75'（换人提速攻坚期）权重上浮至 1.22x，76'-90'+（体能断崖与搏命期）权重上浮至 1.28x。
3. **红牌纪律失衡物理倍数**：
   - 产生红牌时，对受罚方防守失球期望施加 1.75x ~ 2.30x 物理乘数放大，进攻期望削弱至 0.55x ~ 0.65x，优势指数偏移量注入 $\pm 6.5$。
4. **历史交锋与主客场特异性泊松先验闭环**：
   - 在 `interface_features.py` 中激活 `quantitative_prior` 计算，将 H2H 进球均值与主客场积分 PPG 转化为理论期望进球 $\lambda_{prior}$，作为盘口偏离度评估基准。
5. **公允去水与 +EV 价值门禁**：
   - 剥离庄家抽水（Overround），计算真实期望收益率 $EV = P_{model} \times Odds - 1$，仅保留 $EV > 0$ 且价值边际 $\ge +2.5\%$ 的优势方向。
6. **串关组合签名去重与核心腿重叠率熔断**：
   - 在 `parlayRecommendationNormalizer.ts` 中实现票据唯一性签名哈希过滤，拦截所有重复组合；
   - 在 `BettingRecommendationsView.tsx` 中实施专项票互斥生成与 2 串 1 零重叠约束。
