# YBTY盘口与雷速数据导出扩展

## 安装与更新

1. Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 第一次安装选择“加载已解压的扩展程序”。
4. 已安装后更新，只需点击扩展卡片上的“重新加载”。

## YBTY页面

用户自行展开需要采集的联赛和比赛，扩展不会自动展开。

- `导出滚球盘口`：只保存正在进行的比赛，文件名为 `ybty_live_*.json`。
- `导出非滚球盘口`：只保存尚未开始的比赛，文件名为 `ybty_prematch_*.json`。

## 雷速页面

打开 `https://live.leisu.com/`。

- `导出雷速滚球数据`：保存滚球比分、分钟、技术统计、趋势和赔率，文件名为
  `leisu_live_*.json`。
- `导出雷速非滚球数据`：保存未开赛赛事和列表即时盘口，文件名为
  `leisu_prematch_*.json`。

非滚球导出不会逐场打开大量详情页，避免导出时间过长。最终赛前推荐仍需补查
积分战意、近期状态、阵容伤停和当地媒体信息。

## 分析入口

双击项目目录中的 `run_analysis.cmd`，选择：

1. 滚球分析；
2. 非滚球分析；
3. 两种都运行。
